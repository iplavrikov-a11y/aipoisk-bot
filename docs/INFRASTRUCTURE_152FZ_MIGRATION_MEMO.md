## 1. Контекст и стратегическая цель

Для полного соблюдения законодательства РФ (152-ФЗ ст. 18 ч. 5, требований РКН по суверенности данных и ускорению сайтов для пользователей РФ) принято решение перенести **все основные веб-сервисы, бэкенды, фоновые воркеры и базы данных на российский сервер в Москве** (AdminVPS).

На зарубежном сервере (Нидерланды) останется **исключительно легковесный исходящий шлюз / AI-прокси** для обращения к нейросетям (OpenAI, Anthropic, Google Gemini, Groq), которые блокируют прямые запросы с российских IP-адресов.

Это позволяет:
1. **Удешевить зарубежную инфраструктуру**: заменить текущий мощный сервер Нидерландов на ультрабюджетный минимальный VPS (только прокси для AI).
2. **Сделать работу сайтов мгновенной**: база данных PostgreSQL будет работать локально на `127.0.0.1` в Москве (отклик 0.2 мс вместо 35–80 мс через трансграничный туннель).
3. **Обеспечить 100% юридическую чистоту**: все сайты (`tenderlex.ru`, `admin.tenderlex.ru`, почтовые сервисы, клиентские кабинеты) отдаются напрямую с российского IP в дата-центре Москвы.

## 3. Требования к серверу в России (AdminVPS Москва)

Текущий сервер в Москве (`79.133.182.215`) находится на начальном тарифе **Lite** (1 vCPU, 1 ГБ RAM, 15 ГБ диск), на котором сейчас работают только PostgreSQL 14 и почтовый шлюз.  
Перед переносом всех проектов его необходимо **расширить в панели AdminVPS** (кнопка «Сменить тариф» без потери IP и данных).

### Градация конфигураций для сервера в РФ:

| Параметр | Минимальная конфигурация (Start RU) | ⭐ **РЕКОМЕНДОВАННАЯ КОНФИГУРАЦИЯ (Pro RU)** | С запасом на годы (VIP / Конфигуратор) |
| :--- | :--- | :--- | :--- |
| **Процессор (CPU)** | **4 vCPU** (от 3.6 ГГц) | **8 vCPU** (AMD EPYC / Xeon Gold) | **8 – 12 vCPU** |
| **Память (RAM)** | **8 ГБ RAM** (+ 8 ГБ swap) | **16 ГБ RAM** | **24 – 32 ГБ RAM** |
| **Диск (NVMe SSD)** | **80 ГБ NVMe** | **160 ГБ NVMe** | **250 – 300 ГБ NVMe** |
| **Примерная цена AdminVPS** | ~1 289 ₽ / мес | **~3 040 – 3 380 ₽ / мес** | ~4 500 – 5 500 ₽ / мес |
| **Оценка запаса** | **Впритык.** Хватит для всех проектов, но при одновременной сборке фронтенда и тяжелом парсинге возможен свопинг. | **Оптимально.** Все сервисы TenderLex, EmailAgent и базы работают в оперативной памяти без свопа. Высокая скорость выборки БД. | Максимальная мощность. Подходит для масштабирования, одновременного запуска 10+ Chromium браузеров и тяжелых OCR. |

> [!IMPORTANT]
> **Рекомендация для заказа/апгрейда:**  
> Выбирать тариф **Pro (8 ядер / 16 ГБ RAM / 160 ГБ NVMe)**. Это даст надежную производительность без риска OOM-сбоев при одновременной работе TenderLex и EmailAgent.

## 4. Требования к серверу в Нидерландах (AdminVPS NL или Hostkey)

Сервер за рубежом выполняет **исключительно роль исходящего сетевого шлюза (AI Egress Gateway)**.  
На нем не запускаются базы данных, тяжелые парсеры или веб-сайты. Его задача — пересылать HTTPS-запросы к API OpenAI, Anthropic, Gemini, Groq.

### Градация конфигураций для сервера в Нидерландах:

| Параметр | ⭐ **МИНИМАЛЬНАЯ / ОПТИМАЛЬНАЯ (Promo VPS NL)** | С запасом под Playwright (Micro VPS NL) |
| :--- | :--- | :--- |
| **Процессор (CPU)** | **1 – 2 vCPU** | **2 vCPU** |
| **Память (RAM)** | **2 ГБ RAM** | **4 ГБ RAM** |
| **Диск (NVMe SSD)** | **20 – 30 ГБ NVMe** | **40 – 60 ГБ NVMe** |
| **Сетевой канал** | 100 Мбит/с – 1 Гбит/с (трафик от 1–2 ТБ) | До 1 Гбит/с |
| **Примерная цена** | **~499 – 599 ₽ / мес** | **~799 – 899 ₽ / мес** |
| **Назначение** | Идеально для AI-прокси (`cliproxyapi`, SOCKS5 / WireGuard шлюз). Потребление RAM < 500 МБ. | Позволяет при необходимости держать запасной зарубежный браузер для проверки сайтов с зарубежным Cloudflare. |

## 6. Пошаговый план проведения миграции на выходных (2 дня)

### Суббота (День 1): Подготовка инфраструктуры и перенос зависимостей
1. **Апгрейд сервера в РФ в AdminVPS**:
   - В Личном кабинете AdminVPS выбрать сервер `79.133.182.215` -> «Сменить тариф» -> выбрать **Pro (8 ядер / 16 ГБ RAM / 160 ГБ NVMe)**.
   - Дождаться перезагрузки и расширить файловую систему (`growpart /dev/vda 1 && resize2fs /dev/vda1`).
2. **Подготовка окружения на сервере РФ**:
   - Установка Node.js 20/22, Python 3.12, Redis-server, Playwright Chromium dependencies.
   - Настройка Redis для очередей задач.
3. **Настройка зарубежного AI-шлюза (Нидерланды)**:
   - Развертывание легковесного VPS в Нидерландах (или использование текущего со снижением тарифа).
   - Поднятие WireGuard туннеля между Москвой и Нидерландами.
   - Проверка, что запросы к OpenAI и Gemini через шлюз отдают статус 200.

### Воскресенье (День 2): Перенос проектов, переключение трафика и верификация
1. **Синхронизация данных (Rsync)**:
   - Перенос директорий `/root/projects/tenderlex`, `emailagent`, `hermes`, `iva`, `picsbot` с сохранением прав.
   - Финальная досинхронизация баз данных и файлов `storage/`.
2. **Развертывание служб Systemd в РФ**:
   - Активация `tenderlex-api`, `tenderlex-site`, `tenderlex-worker`, `tenderlex-bot`.
   - Запуск служб `emailagent` и вспомогательных ботов.
   - Перевод конфигураций бэкенда на локальный PostgreSQL (`127.0.0.1:5432`).
3. **Переключение Nginx**:
   - Настройка виртуальных хостов всех перенесенных сайтов на локальные порты.
   - Проверка всех маршрутов (сайт, кабинет, админка, боты).
4. **Тестирование и валидация**:
   - Прогон полного набора тестов (`pytest backend/tests`).
   - Проверка авторизации в кабинете, создания задач и генерации отчетов.
   - Контроль ресурсов (`free -h`, `htop`, `df -h`).
5. **Вывод из эксплуатации старого сервера**:
   - Отключение неиспользуемых сервисов на старом сервере в Нидерландах.
