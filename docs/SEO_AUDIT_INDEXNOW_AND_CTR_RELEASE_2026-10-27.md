## 2. Ключевые изменения и технические решения

### 2.1. Автоматическое расширение контура IndexNow (`backend/app/yandex_seo.py`)
- **Проблема**: Ранее функция `submit_indexnow()` отправляла в поисковые системы жестко зашитый список из 12 страниц, оставляя 79 страниц (база знаний, отрасли, регионы) на откуп медленного стандартного краулинга. Вызов очереди переобхода Вебмастера (`POST /recrawl/queue`) периодически зависал по 504 таймауту на стороне серверов Яндекса.
- **Решение**:
  - Реализован метод `_get_sitemap_urls()`, динамически читающий и парсящий `sitemap.xml` проекта (91 канонический URL).
  - Пайплайн `submit_indexnow()` переведен на отправку полного набора из 91 URL через открытый API `https://api.indexnow.org/indexnow` с валидацией ключа хоста (`https://tenderlex.ru/e37d5fc2834b419ea730ef353c7cba2a.txt`).
  - Очередь переобхода Яндекс.Вебмастера защищена таймаутом (5 сек) и перехватом исключений, гарантируя надежность фонового процесса.
  - **Результат верификации**: Все 91 URL успешно отправлены в поисковые системы с кодом ответа `HTTP 200` (`{'ok': True, 'status': 200, 'submitted_count': 91}`).
