# Admin UI 10/10 Scope

## Goal
Bring the AI Poisk admin UI closer to a 10/10 owner-facing operating console.

## Acceptance Criteria
- Visible UI shows only business concepts by default.
- Client limits have exactly two commercial counters: supplier reports and documentation analyses.
- Client cards show usage, remaining limits, shared-manager account context, and recent write-offs.
- Jobs expose human titles and an internal/service flag from backend; service jobs are hidden by default.
- Settings show active supplier search source as backend truth, with technical providers hidden in advanced details.
- AI models show function-level model choices first; provider/API/model IDs stay in advanced details.
- Desktop and mobile screenshots have no horizontal overflow.
- Backend tests, frontend build, and visual audit pass freshly.
