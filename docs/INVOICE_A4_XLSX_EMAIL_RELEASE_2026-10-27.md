# Выпуск 27 октября 2026: Исправление B2B-счетов (Формат А4, Chromium PDF, генерация Excel и Email-рассылка)

## Обзор и контекст

При тестировании функционала выставления счетов для юридических лиц и индивидуальных предпринимателей в боевом личном кабинете (`tenderlex.ru/cabinet`) были выявлены следующие дефекты:
1. **Сжатый/обрезанный вид PDF и веб-превью**: документ отображался в сжатом виде (LibreOffice Calc сжимал 25 строк таблицы в верхнюю треть страницы, а веб-шаблон не соответствовал геометрии реального печатного листа А4).
2. **Ошибка скачивания Excel**: при нажатии кнопки «Скачать Excel (.xlsx)» браузер скачивал текстовый файл ошибки (`download.txt`), так как в виртуальном окружении бэкенда отсутствовал модуль `Pillow`, необходимый библиотеке `openpyxl` для работы с объектами изображений (`openpyxl.drawing.image.Image`).
3. **Ошибка отправки счёта на Email**: всплывало модальное окно `Ошибка отправки email: You must install Pillow to fetch image objects`, а также отсутствовала прямая маршрутизация через почтовый релей платформы.

## Внесённые изменения и архитектурные решения

### 1. Устранение зависимости Pillow для генерации Excel (`backend/requirements.txt`)
- В виртуальное окружение `/root/projects/tenderlex/backend/.venv` установлена библиотека `Pillow 13.0.0`.
- В `backend/requirements.txt` добавлена обязательная зависимость `pillow>=10.0.0`.
- Проверена генерация счетов с наложением синей печати ИП и факсимиле подписи с прозрачным фоном — файл `schet_TL-2026-0001.xlsx` (1.2 МБ) формируется валидным архивом Microsoft Excel 2007+ без сбоев.

### 2. Реализация полноценного формата А4 и генератора Chromium PDF (`backend/app/invoice_service.py`)
- **Веб-просмотр и печать (`render_invoice_html`)**:
  - Карточка документа `.invoice-card` оформлена как физический печатный лист стандарта А4: ширина `210mm`, минимальная высота `297mm`, фоновое полотно `#f1f5f9` с мягкой тенью листа `box-shadow: 0 4px 20px rgba(0,0,0,0.12)` и отступами 1С (`16mm 18mm 20mm 18mm`).
  - При печати через браузер (`@media print`) активирована директива `@page { size: A4 portrait; margin: 12mm 15mm; }`, панель инструментов скрывается (`display: none !important`), а документ заполняет 100% площади бумаги без рамок и теней.
  - В шапку документа добавлена плавающая панель управления с тремя прямыми действиями: `[Распечатать]`, `[Скачать PDF]` и `[Скачать Excel (.xlsx)]`.
- **Генерация векторного PDF (`generate_invoice_pdf`)**:
  - Подключен рендеринг через современный headless Google Chrome (`/usr/bin/google-chrome --headless=new --no-sandbox --disable-gpu --no-pdf-header-footer --print-to-pdf=...`).
  - Устранены браузерные технические колонтитулы (дата, URL, номера страниц).
  - На случай отсутствия Chrome сохранён безопасный fallback на LibreOffice.

### 3. Отправка счетов по Email через Postfix+DKIM релей (`backend/app/invoice_service.py`)
- Функция `send_invoice_email` переведена на использование официального email-релея TenderLex (`http://79.133.182.215:8080/send`), обеспечивающего гарантированную доставляемость и цифровую подпись DKIM.
- К исходящему письму автоматически прикрепляются **оба файла во вложении**:
  - Таблица Excel с формулами и реквизитами (`.xlsx`);
  - Чистый печатный векторный документ А4 (`.pdf`).
- Успешная отправка подтверждена реальным тестом на адрес `79210629909@ya.ru`.

### 4. Обновление пользовательского интерфейса кабинета (`site/src/app/cabinet/cabinet-client.tsx`)
- В блоке «Действия со счётом» кнопки разделены по конкретным сценариям:
  - **Скачать PDF (.pdf)** — прямая загрузка готового А4 PDF-документа.
  - **Скачать Excel (.xlsx)** — прямая загрузка таблицы с реквизитами и формулами.
  - **Печать и просмотр (А4)** — открытие полноразмерного бланка в новой вкладке.
  - **Отправить на email** — отправка письма с обоими вложениями.
  - **Скопировать реквизиты для банк-клиента / 1С** — быстрое копирование текста назначения платежа и банковских реквизитов в буфер обмена.
