# TenderLex: проверка и исправление раздела «SEO и Трафик»

Дата: 4 октября 2026, МСК (публикация и проверки — 3 октября, UTC).

Раздел исправлен и проверен в авторизованной административной панели. Улучшения сайта и решения по SEO выполняются в работе с агентом; панель автоматически показывает состояние аналитики, без согласований и отклонений владельцем.

## Подтверждённые проблемы и исправления

| Проблема до исправления | Результат |
|---|---|
| Кнопки согласования/отклонения рекомендаций, переобхода, отправки в Telegram и ручного обновления | Рабочий процесс согласований удалён из SEO-интерфейса. Панель не отправляет SEO POST-запросы; решения выполняются через агента. |
| При ошибке API состояние загрузки снова запускало тот же запрос без паузы | Ограниченные автоматические проверки каждые 2 минуты, пока раздел открыт и вкладка видима; тайм-аут 90 секунд; отмена запроса при закрытии раздела. |
| После успешной загрузки данные больше не обновлялись | Повторная проверка по таймеру, после возвращения к видимой вкладке и открытия раздела. Последний корректный снимок сохраняется при сбое, с предупреждением. |
| «Позиции растут» / «Снижение позиций» основывались на средней позиции меняющейся выборки | Удалены причинные выводы о ранжировании. Средние позиции показаны по источникам с пояснением зависимости от состава запросов. |
| Общая выборка ограничивалась 100 строками, хотя Google предоставлял 102 фразы | Отдельные выборки Яндекса и Google с явным числом полученных и показанных фраз. Первые 20 строк каждого источника видны сразу; агенту доступен полный ответ API. |
| Общий график требовал выбрать поисковик | Оба графика и обе таблицы доступны сразу. Посуточные даты указаны отдельно от периода популярных запросов. |
| Общий CSS задавал таблицам минимальную ширину 1120 px | В SEO действует отдельная область стилей. На экране 1440 px все столбцы доступны без горизонтальной прокрутки; на телефоне таблицы прокручиваются внутри карточек. |
| Английские служебные сообщения и названия источников визитов | Русские сообщения об измерениях, ошибки загрузки и стандартные названия источников. Названия поисковых фраз и пользовательских целей сохранены. |
| Нулевые визиты за период регистрации выглядели противоречием общему трафику | Период регистраций показан отдельно от общего отчёта Метрики. При нулевом знаменателе процент обозначен прочерком, а не 0%. |
| Актуальность снимка зависела от времени изменения файла | Срок 6 часов считается от `updated_at` сбора источников. Старый или будущий снимок не считается свежим после редактирования файла. Одновременные обычные запросы внутри процесса API не запускают повторный сбор. |

API аналитики возвращает `Cache-Control: no-store`; опубликованный ответ через nginx содержит `no-store, no-cache`. Показано время сбора источников отдельно от времени проверки панели. Двухминутная проверка панели не означает двухминутный сбор данных поисковых систем.

Вынесен самостоятельный `frontend/src/SeoTrafficView.tsx` с отдельными стилями. Из `App.tsx` удалён прежний большой SEO-компонент, редактор ручного предпросмотра сниппета и обработчики согласований. Остальные компоненты администратора сохранены.

- Перед исправлением воспроизведена исходная панель в авторизованном Chrome. Браузерные проверки падали на ручных согласованиях и затем на скрытых столбцах; тесты актуальности снимка — на старом/будущем времени и параллельном сборе. После исправлений проверки прошли.
- Полный backend: **791 тест, 54 подтеста прошли**. Есть 2 существующих предупреждения FastAPI о deprecated startup handlers.
- Финальная production-сборка администратора: TypeScript и Vite прошли. Существующее предупреждение о размере основного пакета свыше 500 kB осталось; новые зависимости не добавлены.
- **11 синтетических браузерных сценариев:** доступные данные, экран 390 px, недоступный источник, HTTP 503, неверная структура ответа, восстановление после ошибки, сохранение снимка при следующем сбое, HTTP 401, вход без перезагрузки, повторное открытие раздела, сетевой сбой. При ошибках нет бесконечного цикла запросов; SEO-запросы только GET.
- **13 проверок действующей панели:** SEO на компьютере и телефоне; все 9 разделов администратора; отсутствие ошибок JavaScript и операций изменения бизнес-данных; настоящий вход через форму без перезагрузки. Неудачных API-запросов не зарегистрировано. Проверка остальных разделов — открытие и загрузка, без выполнения клиентских задач, оплат или изменения настроек.
- Выполнен обязательный `scripts/deploy_tenderlex_live.sh`, область `backend`, после сборки статического администратора. Финальная публикация повторно проверила 35 целевых SEO-тестов и готовность сервисов. Перед перезапусками проверено отсутствие активных задач; штатный сценарий создаёт SQLite backup и удерживает защиту очереди.

## История и пределы результата

Последний предыдущий коммит SEO-кода — `8c7e8ae`, 1 октября 23:01 UTC / 2 октября 02:01 МСК. Последнее изменение карточек задач в администраторе — `cbced3a`, 3 октября; оно сохранено. Исторические аудиты и исходные снимки не переписаны.

Инженерная оценка исправленного SEO-раздела: **9/10**. Проверенные требования к отсутствию согласований, загрузке, отображению источников и адаптивности выполнены. Это оценка функциональности панели одним агентом, а не новая независимая экспертная оценка продвижения.

До безусловной оценки 10/10 остаются наблюдение полного фонового цикла сбора после публикации и расширение проверок на остальные поддерживаемые браузеры. В этой сессии проверен Chrome. Блокировка сбора действует внутри одного процесса API; межпроцессная координация фонового сборщика не добавлялась. Размер основного пакета и старые предупреждения FastAPI записаны выше как существующие ограничения.

Изменения этого раздела сами по себе не доказывают повышение позиций, трафика или регистраций. Для оценки продвижения нужны завершённые сопоставимые периоды и достаточный органический трафик. Переобход, сообщения в Telegram, исходящая рассылка, изменения моделей ИИ и реальные клиентские задания в этой работе не запускались.
